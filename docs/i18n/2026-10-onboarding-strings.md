## SMART steps (onboarding and New goal)

| English | Português |
|---|---|
| Let’s make it | Vamos torná-la |
| Make it clear and detailed, leave no ambiguity. | Escolha algo claro e detalhado, sem ambiguidades. |
| Choose some criteria, you need to know if you are achieving it. | Escolha algum critério, você precisa saber se está dando certo. |
| Your objective should be realistic. | Seu objetivo deve ser realista. |
| Done with frequency | Feito com frequência |
| Isolated events | Eventos isolados |
| The share of check-ins you need to hit to count as on track. Misses are still recorded. | A porcentagem dos registros que você precisa cumprir para ficar em dia. As falhas continuam sendo registradas. |
| What is the reason for this goal? | Qual o propósito dessa meta? |
| You’ll see this reason on Today. | Você vai ver esse propósito em Hoje. |
| SMART comes from English: Specific, Measurable, Achievable, Relevant and Time-bound. | SMART vem do inglês: Specific (específica), Measurable (mensurável), Achievable (atingível), Relevant (relevante) e Time-bound (temporal). |
| How Today and check-ins call it, like “gym”. | Como Hoje e os registros chamam a meta, como “academia”. |
